# 标准规范下载

尽力交付身份正确、版本有据、完整可读的标准规范原文件。覆盖各领域和标准体系；“全部”指可处理范围，不代表所有文件都可免费取得。下载、版本、完整性和水印分别核验。

## 输入与默认值

- 接受标准号、名称、链接或清单；只有主题时先列候选，不能声称覆盖所有适用规范。仅要求“找一下”时先给候选和状态，待选定再下载。
- 确定完整编号、发布机构、国家/地区、年份或版次、分册和语言。同名文档有实质歧义时询问必要信息；企业内部文件通常需要公司名/编号，地方标准需要适用地区。批量中明确的项目继续，不因一项待澄清而停全部。
- 中文报告，PDF 优先，原生 Word 可交付；优先原本无水印的完整原件。官方原生格式为 HTML/TXT/XML 等时保留原件，按需要另做 PDF 阅读副本并标生成方式。默认不把 PDF 转 Word，不将非官方翻译当正式中文版。
- 未指定年份时按该体系官方状态选当前有效/活动的正式版本，并提示已发布未实施新版；指定“最新发布版”、年份、版次或历史日期时按指定目标取得并说明状态。没有统一实施日期的体系不能拿发布日期编造实施日。
- 用户指定保存位置优先，否则正文和报告放工作区 `outputs/`，中间文件放 `work/`。

## 工作流

1. **路由与版本。** 先读 [来源路由](references/sources.md)，只加载相关领域参考。实时查发布机构题录、发布/修订/废止公告，记录核验日期、编号、名称、版次、语言、分册、发布及适用日期、官方状态和替代关系。证据冲突或不可核实时标“版本待核验”；不把搜索摘要或最大年份作为结论。
2. **配套与身份。** 核对修改单、勘误、补遗、局部修订和整本/局部废止，分别交付，不擅自合并成“官方最新版”；官方整合版核实所含修订。工程专项见 [工程路由](references/sources-engineering.md)，国际版次、采标与开放规范见 [国际路由](references/sources-international.md)，企业修订号见 [国内路由](references/sources-china.md)。国内采标版、国际原版、国家采纳版和译本分别核验，不能相互冒充；项目适用性另行判断，不仅凭“现行”推定。
3. **逐级找全文。** 官方全文平台及主管部门/发布机构附件 → 发布机构或授权出版社 → 可交叉核验的公开副本 → 允许保存的完整阅读页。用完整编号/标题/年份和 PDF/Word 等格式独立检索；官方仅有题录时追踪出版、编制/归口机构、地方主管部门和公共图书馆公开资源。未列在参考表的领域也按实际发布机构路由，不因陌生前缀放弃。
4. **实际获取。** 按 [获取方法](references/acquisition.md) 检查附件、阅读器及实际观测的文件地址，使用直接请求、正常下载或浏览器保存/打印。PDF/Word 用 [辅助工具](references/tools-and-results.md) 保存和检查，其他原生格式用适合该格式的工具。允许保存的完整逐页内容可合成“阅读副本”，不能把能看等同于已取得原 PDF。
5. **核验交付。** 核对真实格式、可打开性、封面/文档头的编号版次、目录（如有）、正文连续性、末页、分册/附件、表格公式和水印。扫描件视觉核验，OCR 只作辅助。按 [结果格式](references/tools-and-results.md) 逐项给文件链接、版本和完整性证据、质量说明、尝试方法及具体替代入口。公告、目录、草案、预览、摘要和宣传资料不能冒充全文。

## 获取边界与停止条件

- 准确完整的有水印原件优先于错误或残缺的无水印副本；保留原件，不去除、裁剪或遮盖水印。无水印需视觉证据，不能只凭下载站宣称。
- 使用已有授权的正常访问；登录、验证码、付费或禁止保存时记录障碍并换公开渠道，不绕过限制，不猜受保护接口，不提取账号凭据。购买不自动执行。企业内部资料只用用户提供或授权入口，缺公开全文不代表文件不存在。
- 单地址有限重试；官方、发布/出版及独立副本路线无新线索后结束该项，给可读范围和获取条件。没有全文时说明实际障碍，未实测线索标“待验证”。不承诺免费、无水印或所有规范均可下载。
- 批量每项独立记录；未检索、待澄清、需登录、仅可阅读和未找到分开报告。最新目标仅取得旧版时，旧版另列参考，目标仍未完成。

## 常见误判

文件指纹只证明字节可追踪；页数和 HTTP 200 不证明完整或最新；程序解析不能证明无水印。条文说明、电子附件和数据表按该文档目录/出版说明核对，不要求所有体系具有工程规范结构。版本或完整性未证实时保持“已下载待核验”。
