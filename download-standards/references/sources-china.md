# 国内标准与各领域规范

## 通用题录和公开入口

| 入口 | 路由用途和注意点 |
|---|---|
| [全国标准信息公共服务平台](https://std.samr.gov.cn/) | 身份、主管/归口、状态、替代与公告；导航分流国家、行业、地方、团体、企业及特殊领域 |
| [国家标准全文公开系统](https://openstd.samr.gov.cn/) | 一般国标全文；目标可能下载、阅读或仅题录。食品、环境、工程等还查专门主管部门，不能在这里无全文就结束 |
| [行业标准信息服务平台](https://hbba.sacinfo.org.cn/) | 前缀、备案、主管与全文线索；备案目录不是正文。陌生前缀从题录确认归属 |
| [地方标准信息服务平台](https://dbba.sacinfo.org.cn/) | 地区、编号、备案 → 对应省市市场监管及主管部门发布页；不同地区同名文件不替代 |
| [全国团体标准信息平台](https://www.ttbz.org.cn/) | 团体、编号、状态 → 团体官网正式文本；T/后团体代号不可省，团标不等同强制性国标 |
| [企业标准信息公共服务平台](https://www.qybz.org.cn/) | 企业主体、自我声明、编号、产品和公开范围；可能只公开指标或声明，并非整本正文 |

## 专业分流

| 领域/前缀示例 | 发布与全文路线 |
|---|---|
| 食品安全 GB、食品检测、添加剂 | [国家卫健委](https://www.nhc.gov.cn/)食品安全公告/目录 → 公告指向的 [食品安全国家标准数据检索平台](https://sppt.cfsa.net.cn/) → 官方或地方卫生/疾控公开附件。公告可能提供带端口/路径的入口，按当次公告导航。门户失败时重定位，不把公报里的标准清单当正文 |
| 卫生 WS、WS/T，职业卫生 GBZ、GBZ/T | 卫健委及相关卫生/疾控主管机构正式标准发布与修订页，区分科普和政策解读 |
| 医疗器械 YY、YY/T，药品、药典 | [国家药监局](https://www.nmpa.gov.cn/)及题录指定技术机构；药典核对版次、卷册、增补本和勘误，产品说明书不能代替标准 |
| 环境 GB、HJ、HJ/T | [生态环境部法规标准](https://www.mee.gov.cn/ywgz/fgbz/)标准栏目/附件；正式与征求意见稿、发布与实施、国家与地方标准分开确认 |
| 机械 JB、汽车 QC、电子 SJ、通信 YD、化工 HG、纺织 FZ、轻工 QB 等 | 行业平台定主管 → [工信部](https://www.miit.gov.cn/)等实际主管公告 → 归口/编制机构和授权出版社；公告目录后继续找正文 |
| 农业 NY、粮食 LS、林业 LY、水产 SC | 由题录确认主管，从 [农业农村部](https://www.moa.gov.cn/)、[国家粮食和物资储备局](https://www.lswz.gov.cn/)、[国家林草局](https://www.forestry.gov.cn/)等定位；确认产品、方法和操作规程类型 |
| 应急/矿山/消防 AQ、KA、XF 等 | 题录定主管，从 [应急管理部](https://www.mem.gov.cn/)及矿山/消防发布机构定位；注意前缀迁移、重新编号及局部废止 |
| 金融、信息安全、测绘、海关、管理体系、服务等其他领域 | 统一题录确认机构 → 官网、技术委员会、公开附件和授权出版路线；不限定工程范围 |
| 建筑、市政、交通、水利、电力 | 读 [工程专项](sources-engineering.md)，保留工程修订/强条与条文说明检查 |

前缀仅作线索，主管和入口运行时确认。门户或搜索工具访问失败不代表目标全文不可获取，应从主管部门最新导航、正常浏览器或公开附件继续。

## 企业标准与内部规范

公开 Q/ 标准以完整企业名（必要时信用代码）、完整编号及产品范围确认主体；同简称不证明同企业。自我声明、执行国标声明、指标及标准正文分别标注。

内部作业规程、验收规范、技术条件可从用户文件或已授权入口获取；公司不明或标题有歧义先澄清。记录编号、版本/修订号、原件中的批准/发布机构、生效和废止记录、适用工厂/部门，不凭文件修改时间推定最新版。公开平台查不到不能证明内部文件不存在，不能拿其他公司的同名文件替代。

无法查正式版本台账时，可验证内容和完整性，但标“现行版本未确认”；不擅自向员工发消息求证。
