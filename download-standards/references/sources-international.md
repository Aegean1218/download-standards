# 国际、国外与开放技术规范

## 国际与国外标准

| 体系 | 入口与身份要点 |
|---|---|
| ISO、ISO/IEC | [ISO 标准目录](https://www.iso.org/standards.html)，目标商品页及 Online Browsing Platform；可能只预览。核对 Published/Withdrawn、版次、语言、Amendment/Corrigendum；委员会稿和草案不是正式版 |
| IEC | [IEC Webstore](https://webstore.iec.ch/)；核对 edition、状态、修订单、consolidated version包含范围；稳定或复审日期不是实施日 |
| ASTM | [ASTM](https://www.astm.org/)目录及正常购买/订阅；保留双单位号、年份、字母后缀和括号复审年份，reapproved不自动等同技术修订 |
| IEEE | [IEEE Standards Association](https://standards.ieee.org/)目标页 → 标准渠道；区分 active/inactive/superseded/draft和修订，会议论文不是标准 |
| EN、EN ISO、EN IEC | [CEN-CENELEC](https://www.cencenelec.eu/) → 国家成员机构；核对欧洲版本、国家采纳版、国家前言/附录、修订，不以ISO原版替代BS EN/DIN EN目标 |
| BS、DIN、NF、JIS、AS/NZS等 | 对应国家标准/出版机构；可从 [BSI](https://www.bsigroup.com/)、[DIN](https://www.din.de/)、[AFNOR](https://www.afnor.org/)、[JISC](https://www.jisc.go.jp/eng/)、[Standards Australia](https://www.standards.org.au/)、[Standards New Zealand](https://www.standards.govt.nz/)定位目录，语言/下载/授权按目标页确认 |
| ASME、API、SAE、UL等 | 发布机构官方目录；核对edition、addenda、errata、卷册。样章、培训和介绍不是全文；ANSI字样不自动代表ANSI是正文发布者 |
| 其他体系/无编号规范 | 从完整机构名、原文标题、地区和版次确认发布者，沿官方/出版路线继续；本表未列不是拒绝理由 |

国际/国外标准无通用实施日。保留官方状态原文及中文解释，未公布日期填“不适用/未公布”，不能用发布、确认、复审、稳定期限或国家转版截止日替代。合同/认证/监管过渡安排另查，最新出版不等于某项目必须采用。

未指定语言优先发布机构正式中文全文，没有则交付可取得的正式语言原件并说明；机器翻译/第三方译本另列。国内IDT/MOD/NEQ采标关系可记录，但国标、国际原版、国家采纳版的状态/修订/附件分别核验，不能跨标准报完成。

基础版、官方整合版、红线版不是同一出版物；核对所含修订后交付。基础正文配修订单分文件保存，不自行拼接为官方整合版。

## 开放协议与技术规范

| 体系 | 路由与状态检查 |
|---|---|
| RFC/IETF | [RFC Editor](https://www.rfc-editor.org/)目标info页及 [IETF Datatracker](https://datatracker.ietf.org/)；RFC号对应固定发布文档，指定号保留原号，另报 Obsoletes/Obsoleted by、Updates/Updated by及errata。Internet Standard、Proposed Standard、BCP、Informational等不能混称强制性标准。Internet-Draft不是RFC，未核准勘误不能默默改写正文 |
| W3C | [W3C standards and drafts](https://www.w3.org/TR/)；区分Recommendation、Candidate Recommendation、Working Draft。保存带日期固定版并记录当前入口/替代关系；编辑草案不能冒充正式Recommendation |
| ETSI | [ETSI Standards](https://www.etsi.org/standards/)；核对编号、EN/TS/TR/ES类型、Vx.y.z、日期和原文件；同号不同版不混用 |
| 3GPP | [3GPP](https://www.3gpp.org/)导航到Specifications；保留specification number、Release、version及包内目标附件，Release不是年份，不能只挑最大文件名 |
| ITU | [ITU Recommendations](https://www.itu.int/rec/)；核对系列、版本日期、修订单、状态及官方格式；免费/账号条件按目标页实测 |

官方HTML/TXT/XML/PDF/ZIP可保留合适原生格式。现有辅助脚本只检查PDF/Word，不能把其他格式交给脚本后以“不像PDF”否定正文。其他格式用普通HTTP/浏览器保存，核对编码、完整结构、文档头、章节/目录及末尾；ZIP查内部清单并核验目标文件，不能只交压缩包就声称正文核验。需PDF时生成标注来源的阅读副本，检查完整正文、图表和分页；不强行生成Word。

以上为发现入口，不是全文保证。搜索工具返回403、无可解析正文或超时时，按获取参考尝试正常HTTP/浏览器及其他公开/授权渠道，记录具体失败方法，不把工具访问失败当作全网不可下载。
