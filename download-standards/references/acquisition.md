# 文件与阅读页获取

## 从页面寻找实际文件

1. 用搜索找到正式发布页并打开；先分辨是题录、全文、公告、征求意见还是购买页。记录标准身份和官方证据。
2. 检查页面可见附件，以及实际 HTML/DOM 中 `a[href]`、`iframe[src]`、`embed[src]`、`object[data]`。相对地址按来源页 URL 解析，HTML 实体解码。需要时读页面引用的公开脚本中实际附件数据；只检查已发现页面，不猜受保护接口。
3. 阅读器可能使用 PDF.js 的 `file=` 参数、公开 PDF 响应、图片页或浏览器 `blob:`。从页面和可用浏览器工具实际观测到的资源地址取文件。`blob:` 不能直接用 HTTP 下载；用页面正常下载/打印，或浏览器能力支持的保存方式。
4. 短期签名链接立即使用，不长期写死。HTTP 工具访问失败但浏览器能正常访问时，可用正常浏览器下载/导出；不得把失败 HTML 换扩展名当 PDF。若工具无法观测网络/下载路径，如实说明，不假造支持的 API。
5. 如果搜索工具失败/超时，用已知官方入口正常 HTTP 或浏览器尝试；站点本身 401/403/验证码时停止该受限地址，换独立公开来源。不要关掉 TLS 校验来求下载。

## 请求上下文

- 下载辅助工具接受已发现的 URL 和目标路径；必要时带来源页 Referer。仅使用实际需要且已有授权的请求上下文。
- 已登录数据库优先在浏览器原会话中操作。脚本的 `--headers-file` 仅用于用户明确提供/授权的请求头；不从浏览器、钥匙串、账号文件提取 Cookie，不把凭据放命令行或分享报告。
- 头文件放私有中间目录，任务后移除，不打包；跨来源跳转不转发认证头。短期 URL 的访问令牌在日志和分享报告中隐藏。
- 每地址最多 3 次常规尝试；网络/部分服务端临时错误可退避，401/402/403/404 不机械重试。429 尊重站点限流，持续限流则换路或结束并记录；重试不能升级为绕过限制。
- 保存临时文件后检查真实格式和解析结果，再原子发布；不覆盖已有文件。不同来源用不同文件名，确认 SHA-256 相同时才去重。正文保持原字节。

## 在线阅读的分支

| 观测结果 | 行动及名称 |
|---|---|
| 阅读器加载可保存的完整原始 PDF | 下载并记录实际来源；仍核验身份与完整性 |
| 官方完整 HTML 正文，允许打印/保存 | 正常打印为 PDF；标“网页打印阅读副本”，检查分页、公式、表格和附录 |
| 全部页图/单页 PDF 可读取且允许保存 | 收集所有已观察页，确认总页数与顺序，用 `assemble_pages.py` 合成“阅读副本” |
| 只有预览/节选 | 明确可见范围，继续找全文，不将可见页当完整标准 |
| 全文可看但禁止下载/打印保存，或保存需要未取得的权限 | 交付在线阅读入口和所需权限/其他渠道，不绕过限制 |

逐页收集不要推测或枚举隐藏、受保护页。仅对实际有权访问且允许保存的页使用有限并发；不能通过提高并发规避限流。总页数未知或缺页时不生成“完整副本”。页面号码、封面/目录/空白页都计入阅读器总页数，不能仅按正文印刷页码计数。数字连续是最低条件，还需视觉检查内容对应、重复页和截断。

`assemble_pages.py` 接收本地有序页清单，会拒绝缺失或重复页号以及多页 PDF 条目。图片无需重新截图加工，保持已取得的原页清晰度与水印。合成 PDF 的元数据标明阅读副本，不添加会遮盖正文的文字。生成方式和来源另记于报告。

## 完整性与水印

- 检查封面、前言、目录、全部正文页、附录、引用标准/用词说明、末页及目录要求的内容。印刷页号与 PDF 页数不同，前置页和空白页不是缺页。
- 程序遍历各页可发现低文本页和解析异常；视觉核对页面连续性。必要时制作低分辨率全页接触表发现空白/重复/缺页，并放大检查封面、目录、章节过渡、图表及末页。
- 扫描件保留原件，OCR 只作为可选检索副本和辅助证据，不能把 OCR 对公式/数字的猜测作为官方条文。
- 若报告“无水印”，需视觉检查全部页面；只检查部分页面时写“抽检未见水印，全部页面未确认”。程序未找到水印文字不能证明无水印。
- 页数、文件长度、SHA-256、HTTP 200 都不能单独证明完整性；没有目录/全页/末页证据时标待核验。

工程规范之外按文件真实出版结构检查：HTML/TXT 可用完整文档头、全部章节、参考文献和文档末尾等证据；本来没有目录或固定页数时如实说明。不得把“不具有工程目录”视为不完整，也不能忽略正式说明要求的配套表格、电子附件或多个分册。
