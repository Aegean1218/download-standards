# 验证范围

## 自动测试

```sh
python -m pip install -r download-standards/tests/requirements.txt
python -m unittest discover -s download-standards/tests -v
```

24项测试使用临时PDF、DOCX、图像和本地HTTP服务，不依赖商业数据库账号、真实标准正文或外部网站。

覆盖真实格式、HTML伪装PDF、损坏/扫描/草案、年份/页数不符、Word分页未定、阅读页顺序/缺页/重号、原字节/指纹、重定向、认证头保护、有限重试和限流、错误清理、不覆盖、报告路径冲突、敏感URL脱敏、批量局部失败及技术成功不自动宣称核验。

GitHub Actions配置在推送和Pull Request运行Python 3.10与3.12测试；配置存在不表示远程CI已运行或通过。

## 行为与真实来源检查

扩展时独立离线检查了质量管理国标、ISO、食品安全、RFC、主体不明的企业规范，以及预览、采标替代、ETSI同号不同版、官方TXT和公告仅清单情形。确认不虚构版本、下载和无水印结论，待澄清项不阻断明确项。

已有工程规范官方附件获取和全页视觉核验经验；扩展时另从RFC Editor取得RFC 8259原生TXT，核对文档头、14章、附录A、印刷页标记1—16及末尾。真实标准全文和本机核验日志不随仓库分发。

检查只说明所测操作和判断，不证明所有站点当前开放或所有版本/附件可得。每次任务仍实时查具体题录、修订和权限。

## 通过条件

身份和版本有正式证据，文件可打开，出版结构/页面/附件完整，异常已解释和解决；水印另列质量字段。HTTP 200、指纹、页数或解析成功不能单独证明通过。

技能结构可用Codex内置skill-creator的quick_validate.py分别检查主技能和兼容入口；本仓库不依赖该系统脚本，没有时人工检查frontmatter、命名、链接和调用配置。
